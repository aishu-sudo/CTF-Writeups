Burp Suite Setup & HTTPS Intercept (YouTube Request)

Name: FIREWALL FAIRY
Date: 19 September 2025
Source: Cyberwings Security — “What is Burp Suite and How to install Burp Suite” (YouTube).

Executive summary

On 19 September 2025 I installed Burp Suite Community Edition and configured Firefox to proxy through Burp. I imported Burp’s CA certificate to enable HTTPS interception, and successfully intercepted and forwarded an HTTPS
GET
request to YouTube. This exercise showed how Burp can inspect encrypted traffic and the workflow: intercept → inspect → forward.

Objective

Install Burp Suite Community Edition and verify proxy listener.
Configure Firefox to use Burp as HTTP/HTTPS proxy.
Import Burp CA certificate into Firefox Authorities.
Intercept, inspect, and forward an HTTPS request for a YouTube video.

Tools / Environment

OS: [Windows / Ubuntu / Kali Linux, etc.]
Browser: Firefox (testing profile)
Burp Suite: Community Edition — default listener
127.0.0.1:8080
.
Target: YouTube —
https://www.youtube.com/

Methodology

Launched Burp Suite → Proxy → Options → verified listener
127.0.0.1:8080
.
Configured Firefox → Settings → Network Settings → Manual proxy → HTTP proxy
127.0.0.1
port
8080
.
Exported Burp CA certificate from Burp and imported to Firefox → Preferences → Privacy & Security → Certificates → Authorities → ticked Trust this CA to identify websites.
Enabled Proxy → Intercept in Burp (Intercept is on).
In Firefox, opened the YouTube URL — Burp intercepted the
GET /
request.
Inspected the request in Burp, then clicked Forward to complete the request.

Raw intercepted request

Plain Text
Copy
GET / HTTP/1.1 Host: www.youtube.com User-Agent: Mozilla/5.0 (X11; Linux x86_64; rv:91.0) Gecko/20100101 Firefox/91.0 Accept: text/html,application/xhtml+xml,application/xml;q=0.9,image/webp,*/*;q=0.8 Accept-Language: en-US,en;q=0.5 Accept-Encoding: gzip, deflate Referer: https://www.youtube.com/ Cookie: [REDACTED] Connection: close
​

Analysis

HTTPS interception only worked after importing Burp’s CA certificate into Firefox.
The captured request included YouTube cookies and dynamic headers. Cookies were redacted before saving.
After forwarding the request, the video loaded normally in the browser.
Using Repeater you can test header/query modifications; however, services like YouTube may respond differently or redirect.
Appendix:
Step 1:Burp Proxy → Options showing listener 127.0.0.1:8080
Step 2:Firefox Network Settings showing manual proxy config
Step 3:Firefox Certificate Manager showing imported Burp CA.
Step 4:Burp Proxy → Intercept with captured GET / HTTP/1.1
